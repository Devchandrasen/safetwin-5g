# Phase 7 Dataset v2a Contract

`safetwin5g-named-actions-v2a` is the public-safe data object for the frozen
BRACE precision-amendment campaign. A release is eligible only after all 675
units form 135 complete five-action blocks and the source command/trace bundle
passes its SHA-256 and clean-recovery audit.

The common action outcome is the maximum of mean packet-loss percentage and
the percentage-equivalent UPF-down indicator. Within a block, observed benefit
is the observe-only burden minus the named-action burden. A certificate-margin
violation is a selected mutation with benefit at most five points. A harmful
action is a mutation with benefit below minus five points, or any mutation in
a no-fault block. These are distinct endpoints.

The release retains the hashed approval identifier and the facts that a
mutation was reversible, approval-gated, rollback-planned, and cleanly
recovered. It excludes authorization prose and identities. Evidence remains
`sandbox-measured` for interventions and `simulated` for radio access; hardware
measurement and operator validation remain absent.

Pilot bundles can exercise the parser and structural checks but cannot become
a frozen release. Test labels must remain sealed until the Phase 7 analysis
code and hashes are frozen.
